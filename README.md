I'm a software engineer building backend systems and AI-integrated tools, currently pursuing my M.S. in Software Engineering at Arizona State University. What I enjoy most is taking an LLM past the point of just answering questions — hooking it up to real data and having it actually do something useful. That's what pushed me to build **MapMind** over a weekend: an assistant that reasons over real map data instead of just talking about it.

Outside of that, I'm working through core backend and system-design fundamentals with the same bias toward shipping — finished, working projects over half-built tutorials.

> Build it end-to-end, then make it good.

## Projects

**[MapMind](https://github.com/aarchie25/mapmind)** — an LLM-powered geospatial assistant that answers natural-language location questions using real map data. Built end-to-end in a single weekend for a technical interview with ASU's SHARES research program; deployed on Railway (backend) and Streamlit Cloud (frontend).
`Python` `FastAPI` `Streamlit` `Groq / LLaMA3` `OSMnx` `GeoPandas`

**JobLens** — a full-stack job-search tool with a cleanly separated frontend/backend, built around a well-structured REST API.
`Python` `TypeScript` `REST APIs`

**YADA Programming Language** — a small language built with a team, complete with its own lexer, parser, semantic analysis, and runtime.
`Compiler Design` `Lexing & Parsing` `Team Development`
