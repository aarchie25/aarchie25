## 👨‍💻 About Me

I'm a software engineer interested in **backend systems, scalable architectures, and AI-integrated applications**.

What interests me most about AI isn't just getting an LLM to answer questions — it's connecting models to **real data, APIs, tools, and software systems** so they can solve useful problems.

That idea pushed me to build **MapMind**, an LLM-powered geospatial assistant that reasons over real-world map data instead of simply talking about locations.

My broader engineering focus sits at the intersection of **backend development, distributed systems, and applied AI** — designing systems that are maintainable, observable, reliable, and useful beyond the prototype stage.

> **Build it end-to-end. Understand how it works. Then make it better.**

## 🚀 Featured Engineering Work

### 🗺️ [MapMind](https://github.com/aarchie25/mapmind)

**LLM-powered geospatial assistant that reasons over real-world map data.**

Built end-to-end for a technical interview with ASU's SHARES research program. MapMind combines LLM reasoning with geospatial tooling to answer natural-language location questions using actual map data rather than relying solely on a model's internal knowledge.

`Python` · `FastAPI` · `Streamlit` · `Groq / LLaMA 3` · `OSMnx` · `GeoPandas`

#### Architecture

```text
Natural Language Query
        │
        ▼
   Streamlit UI
        │
        ▼
    FastAPI API
        │
        ├────────► LLM Reasoning
        │
        └────────► Geospatial Tools
                         │
                         ▼
                    Map Data
```

**Deployment:** Railway (Backend) · Streamlit Cloud (Frontend)
